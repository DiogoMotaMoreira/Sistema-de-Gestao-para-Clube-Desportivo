# Casos de Uso do SIGD

O ficheiro PDF `usecases.pdf` na pasta references/ contém todos os UCs detalhados.

## Módulos:
- **Módulo A — Secretaria:** UC-01 a UC-05 (Atletas, EE, Inscrições, Pagamentos, Épocas)
- **Módulo B — Treinador:** UC-09 a UC-11 (Assiduidade, Convocatórias, Fichas de Jogo)
- **Módulo C — Direção Técnica:** UC-06 a UC-08 (Hierarquia, Calendário, Análise)
- **Módulo D — Portal:** UC-14, UC-15 (Upload Docs, Consultas)
- **Módulo E — Departamento Médico:** UC-12, UC-13 (Ocorrências, EMDs)

Cada UC contém: atores, pré/pós-condições, fluxo normal passo a passo,
fluxos alternativos e fluxos de exceção.
